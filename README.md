# 📊 Customer Churn Analysis using Python & SQL

## 📌 Project Overview

Customer churn is one of the biggest challenges faced by subscription-based businesses. This project analyzes customer behavior using Python, SQL, and data visualization techniques to identify the factors that influence customer churn and provide business insights that help improve customer retention.

---

## 🎯 Project Objectives

- Analyze customer churn patterns.
- Clean and preprocess raw customer data.
- Store and retrieve data using SQLite.
- Perform Exploratory Data Analysis (EDA).
- Identify important features influencing churn.
- Generate business insights through visualizations.
- Export cleaned data for reporting and dashboard creation.

## 🔄 Project Workflow

### 1. Data Import
- Load customer data from SQLite database.
- Optionally create the SQLite database from the Excel file.

### 2. Data Cleaning
- Rename columns.
- Remove unnecessary columns.
- Handle missing values.
- Convert data types.
- Prepare data for analysis.

### 3. Exploratory Data Analysis
- Analyze customer demographics.
- Study churn distribution.
- Explore service usage.
- Compare customer segments.
- Identify churn trends.

### 4. Visualization
Generate charts to understand:

- Customer churn rate
- Contract type distribution
- Monthly charges
- Tenure analysis
- Payment methods
- Internet services
- Senior citizen analysis

---

## 📈 Business Insights

The analysis helps answer questions such as:

- Which customers are most likely to churn?
- Which contract type has the highest churn?
- Does tenure affect churn?
- Does monthly charge influence customer retention?
- Which services reduce customer churn?
